# 90 · Guía rápida por rol

Una página por rol, con las cinco tareas que más se repiten. Si necesitas el
detalle, sigue el enlace al módulo.

---

## Director

Ve todo el colegio. Es el único que puede emitir solvencias manuales, cerrar
lapsos, generar boletines y consultar la auditoría.

### 1. Revisar cómo va el colegio hoy

Menú lateral → **"Dashboard"**. Mira **"En mora"** y **"Cobranza hoy"**.
→ [Dashboard](03-dashboard.md)

### 2. Ver quién le debe al colegio

Menú lateral → **"Morosos"** → **"Ordenar por días de atraso"** → **"Exportar
morosos a Excel"** si necesitas trabajarlo aparte.
→ [Morosos](22-morosos.md)

### 3. Generar el boletín de un alumno

Menú lateral → **"Boletines"** → busca al alumno → elige el lapso →
**"Vista previa"** → **"Descargar PDF"**.
→ [Boletines](15-boletin.md)

### 4. Emitir una solvencia manual

Menú lateral → **"Solvencia"** → escribe la cédula → **"Buscar"** → escribe el
motivo → **"Emitir solvencia manualmente"**.
→ [Solvencia](24-consulta-solvencia.md)

### 5. Revisar quién hizo qué

Menú lateral → **"Auditoría"** → filtra por **"Desde"** / **"Hasta"** y por
módulo.
→ [Auditoría](06-auditoria.md)

---

## Secretaria

Su día gira alrededor de inscribir, mantener los datos de alumnos y
representantes, y control de estudios.

### 1. Inscribir un alumno

Menú lateral → **"Inscripciones"** → paso 1 cédula del representante → paso 2
datos del alumno → paso 3 grado y tipo de ingreso → **"Confirmar Registro"** →
**"Descargar Comprobante"**.
→ [Inscripciones](08-inscripciones.md)

### 2. Reimprimir un comprobante de inscripción

Menú lateral → **"Consulta de Inscripción"** → busca por nombre → descarga.
→ [Consulta de Inscripción](09-consulta-inscripcion.md)

### 3. Generar la planilla de pre-inscripción

Menú lateral → **"Pre-Inscripción"** → busca al estudiante → marca los campos →
**"Generar"**.
→ [Pre-Inscripción](07-preinscripcion.md)

### 4. Sacar el listado de una sección

Menú lateral → **"Grados"** → elige el grado → **"Excel"** o **"PDF"**.
→ [Grados](12-grados.md)

### 5. Pasar asistencia

Menú lateral → **"Asistencia"** → elige grado y fecha → marca a cada alumno →
**"Guardar asistencia"**.
→ [Asistencia](16-asistencia.md)

---

## Cajero

Su trabajo es cobrar y cerrar bien la caja.

### 1. Cobrar una mensualidad

Menú lateral → **"Cobranza"** → escribe la cédula y Enter → marca las cuotas →
**"Ir a registrar pago"** → método, banco y referencia → **"Registrar Pago"**.
→ [Cobranza](20-cobranza.md)

### 2. Reimprimir un recibo

Menú lateral → **"Comprobantes"** → filtra por **"Nº Recibo"** o nombre →
**"Buscar"** → **"Imprimir recibo completo A4"**.
→ [Consulta de Comprobantes](23-comprobantes.md)

### 3. Consultar si una familia está solvente

Menú lateral → **"Solvencia"** → escribe la cédula → **"Buscar"**.
→ [Solvencia](24-consulta-solvencia.md)

### 4. Abrir y cerrar la caja de la cantina

`/cantina` → **"POS"** → declara el monto inicial. Al final del turno:
**"Cierre de caja"** → **"Conteo físico"** → **"Registrar cierre"**.
→ [Cantina](33-cantina.md)

### 5. Aprobar una recarga de tarjeta

`/cantina` → **"Tarjetas"** → **"Recargas pendientes de revisión"** → verifica el
comprobante → aprueba o rechaza.
→ [Cantina](33-cantina.md)

---

## Cobranza

Sigue las deudas y ordena los pagos que entran.

### 1. Revisar la mora del día

Menú lateral → **"Morosos"**. Cruza con el **"Dashboard de Cobranza"**.
→ [Morosos](22-morosos.md) · [Dashboard de Cobranza](21-cobranza-dashboard.md)

### 2. Verificar si un pago entró al banco

Menú lateral → **"Conciliador"** → elige el banco → sube el estado de cuenta →
**"Buscar por referencia"**.
→ [Conciliador](25-conciliador.md)

### 3. Clasificar un depósito que cubre varios conceptos

Menú lateral → **"Reportes"** → **"Clasificación de Pagos"** → abre el pago →
agrega una línea por concepto.
→ [Reportes](04-reportes.md)

### 4. Sacar el cierre de caja del día

Menú lateral → **"Reportes"** → **"Cierre de Caja"** → **"Desde"** / **"Hasta"**
→ descarga en PDF o Excel.
→ [Reportes](04-reportes.md)

### 5. Corregir o anular un pago mal cargado

Menú lateral → **"Reportes"** → **"Corrección de Pagos"** → busca el pago →
corrige o anula, siempre con el motivo escrito.
→ [Reportes](04-reportes.md)

---

## Administrador

Lleva la parte administrativa y financiera del plantel.

### 1. Ajustar los montos del colegio

Menú lateral → **"Alumnos"** → **"Configuración"** → **"Mensualidad ($)"**,
**"Inscripción ($)"** y **"Proyecto de Inversión ($, por representante)"**.
→ [Alumnos](10-alumnos.md)

### 2. Registrar un empleado

Menú lateral → **"Nómina"** → elige la pestaña del tipo de personal →
**"Registrar"**.
→ [Nómina](28-nomina.md)

### 3. Generar la nómina del mes

Menú lateral → **"Nómina"** → **"Generar nómina"** → mes, año, tasa y
cestaticket.
→ [Nómina](28-nomina.md)

### 4. Generar los archivos para el banco

Menú lateral → **"Pagos"** → elige **"Nómina"**, **"Incentivo"** o
**"Cestaticket"** → genera el TXT.
→ [Módulo de Pagos](27-pagos.md)

### 5. Publicar una circular

Menú lateral → **"Circulares"** → **"Nueva Circular"** → título y contenido →
**"Publicar Circular"**.
→ [Circulares](29-comunicacion.md)

## Docente

Trabaja solo con sus materias y sus alumnos.

### 1. Cargar notas

Portal Docente → **"Materias"** → abre la materia → pestaña **"Notas"** → elige
el lapso → escribe las notas → guarda.
→ [Portal Docente](32-portal-docente.md)

### 2. Pasar asistencia

Portal Docente → **"Materias"** → abre la materia → pestaña **"Asistencia"** →
elige la fecha → marca a cada alumno → guarda.
→ [Portal Docente](32-portal-docente.md)

### 3. Armar el plan de evaluación

Portal Docente → materia → pestaña **"Plan de Evaluación"** → crea el bloque y
sus ítems.
→ [Portal Docente](32-portal-docente.md)

### 4. Escribirle a un representante

Portal Docente → **"Mensajes"** → **"Nueva conversación"** → elige al alumno.
→ [Portal Docente](32-portal-docente.md)

### 5. Registrar un incidente

Portal Docente → **"Incidentes"** → elige al alumno → descripción y severidad →
guarda.
→ [Portal Docente](32-portal-docente.md)

## Representante

Entra desde el teléfono.

### 1. Ver cuánto debo

`/portal` → **"Inicio"**. Verás **"Solvente — al día con los pagos"** o
**"Deuda pendiente"**.
→ [Portal de Representantes](31-portal-representantes.md)

### 2. Reportar un pago

**"Inicio"** → **"Pagar por transferencia"** → sube el comprobante, elige el
método y escribe la referencia.
→ [Portal de Representantes](31-portal-representantes.md)

### 3. Ver las notas de mi hijo

**"Rendimiento"**. Si tienes varios hijos, cambia de estudiante arriba.
→ [Portal de Representantes](31-portal-representantes.md)

### 4. Descargar un recibo

**"Historial"** → elige el pago → descarga.
→ [Portal de Representantes](31-portal-representantes.md)

### 5. Recargar la tarjeta de la cantina

**"Cantina"** → recarga → moneda, monto, banco, referencia y comprobante.
→ [Portal de Representantes](31-portal-representantes.md)
